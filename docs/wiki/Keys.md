Cue is driven from the keyboard. The bar at the bottom of each screen shows the keys that
work there.

## Everywhere

| Key | What it does |
|---|---|
| `↑` `↓` / `j` `k` | Move (`h` `l` too in the episode grid) |
| `Enter` | Choose or play |
| `/` | Jump to the text box: search on Home, filter on Results, an episode range on Episodes |
| `Esc` | Leave a text box |
| `Tab` | Switch [search group](Search-Groups) (Movies, Shows, Anime, ...) |
| `q` | Back, or quit from Home |
| `Ctrl+P` | Command palette |

## Home

| Key | What it does |
|---|---|
| `s` | Settings: subtitles, and the way to the Plugins menu (after `Esc` if you're in the search box) |
| `p` | The Plugins menu: providers, groups, players, subtitle sources and plugins (after `Esc` if you're in the search box) |

The Home screen also lists **Continue Watching**: the shows you were part-way through.

## Episodes

| Key | What it does |
|---|---|
| `Enter` | Play from the highlighted episode, or the typed range |
| `d` | Download the highlighted episode, or the typed range |
| `t` | Cast to a TV: every episode, or the typed range. See [Casting](Casting) |
| `b` | Switch HiAnime between SUB and DUB (also shown as a selector) |

**Episode ranges** work like ani-cli's. Type one in the range box and press `Enter` to
play those episodes in order, or `Esc` then `d` to download them:

| Range | Means |
|---|---|
| `3` | Episode 3 |
| `1-5` | Episodes 1 to 5 |
| `1 5` | Episodes 1 and 5 |
| `-1` | The latest episode |
| `3--1` | Episode 3 to the latest |
| `1-3,7` | Several, joined with commas |

## Now Playing

| Key | What it does |
|---|---|
| `n` / `p` | Next / previous episode |
| `r` | Play the current episode again |
| `s` | Jump ahead 85 seconds (a manual skip) |
| `a` | Turn auto-skip on or off |
| `c` | Cycle through the loaded subtitles |
| `Shift+C` | The subtitle picker: every server track and every subtitle source's results |
| `t` | Send to TV: stop here, save your place, and cast this episode and the rest |
| `q` | Stop, saving your place |

## Settings

| Key | What it does |
|---|---|
| `Enter` | Open the highlighted section |
| `Ctrl+S` | Save a section's settings |
| `q` / `Esc` | Back |

## Plugins menu

`←` and `→` switch tabs. Each tab's keys are listed on the [Plugins](Plugins) page.

## Cast picker

| Key | What it does |
|---|---|
| `Enter` | Cast to the highlighted TV |
| `r` | Look for TVs again |
| `Esc` | Cancel |
